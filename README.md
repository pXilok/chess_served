# Chess Trainer Server

Серверная часть проекта по ТЗ (Часть 2). FastAPI-сервер бизнес-логики
шахматного тренажёра.

## Что умеет

- Хранение шахматных партий в базе данных SQLite
- Генерация игр — выдача случайной партии из архива
- REST API с автоматической документацией Swagger
- Валидация данных через Pydantic
- Асинхронные эндпоинты

## Стек

- Python 3.13
- FastAPI + Uvicorn
- SQLAlchemy (ORM)
- SQLite (база данных)
- Pydantic (валидация)

## Эндпоинты

| Метод | Путь | Что делает |
|-------|------|------------|
| GET | `/health` | Проверка работы сервера |
| POST | `/api/v1/games` | Создать новую партию |
| GET | `/api/v1/games/random` | Случайная партия (генерация игр) |
| GET | `/api/v1/games/{game_id}` | Партия по ID |

## Запуск

1. Установить зависимости:
2. pip install fastapi uvicorn sqlalchemy
3. Создать таблицы в базе (один раз):
4. python init_db.py
5. запустить сервер
6. uvicorn server:app --reload
7. открыть документацию 
8. http://127.0.0.1:8000/docs

## Структура

- `server.py` — FastAPI приложение и эндпоинты
- `database.py` — подключение к SQLite
- `models.py` — модель таблицы `games`
- `init_db.py` — создание таблиц
- `chess.db` — файл базы данных (создаётся автоматически)
